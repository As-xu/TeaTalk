## 3 已知缺口（不阻塞 M1 关闭）

1. **HTTP 状态码未展示**：401/429 有专属文案；其它 4xx/5xx 统一 `Server returned an error`。后续在 `ChatError.HTTP` 里带 `code` 即可（改 strings + UiText）。
2. **429/超时/断流未实测**：本次只实测了 404（httpbin）。断流可后续用开关「模拟断流」或本地 mock 验证。
3. **真机未回归**：本步骤只在 AVD 验证；真机（HarmonyOS 4.2 / API 31）留一次回归。
4. **prompt 仍是单条 system + 最近消息**：世界书扫描、宏、预算裁剪尚未接入（M2/M3）。
