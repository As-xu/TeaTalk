# UX 设计层（第一轮样张，待检视）

> 状态：**第一轮样张已产出，等待用户检视**（2026-10-25）
> 产出物：`design/` 模块（可安装的样张 App）+ `docs/design/samples/`（并排对比图）

## 1. 本轮做了什么

按「QQ 风格 + 角色扮演基调 + 暖色调」的目标，做了一版**可交互的高保真样张**，不是静态图：

| 能力 | 说明 |
|---|---|
| 3 套配色 | A 奶油茶（茶褐 + 暖白）/ B 奶咖（深咖 + 米白）/ C 青瓷（墨绿 + 暖白） |
| 1 套暗色 | 奶油茶夜（用户要求保留深色模式） |
| 5 个页面 + 1 个规格页 | 会话列表 / 角色 / 角色详情 / 聊天 / 我的 / 设计规格 |
| 真实素材 | 角色卡头像与封面取自 `.tools/cards/real/`（用户提供的真实卡，挑了 6 张非露骨卡） |
| 可切换 | 右上角隐形热区 → 底部弹层切换配色与页面；无痕，不影响截图 |

样张 App 是**独立模块** `design/`（applicationId `com.teatalk.design`），
`./gradlew :design:assembleDebug` 单独出包，不会混进正式包。

## 3. 设计要点（与 QQ 对齐的部分）

| 区域 | 做法 |
|---|---|
| 会话列表 | 顶部 头像+在线状态+搜索（QQ 首页同构）；会话行 52dp 圆角头像 + 标题 + 最后一条消息 + 时间；置顶角标、未读角标 |
| 角色页 | 2 列大卡（图 + 名字 + 作者），顶部分段（最近/全部/收藏）+ 搜索；QQ 联系人页的网格感 |
| 详情页 | 封面图 + 底部渐变到背景 + 大标题/作者/标签；主 CTA「开始聊天」+ 次按钮「世界书 N」；简介/开场白/设定分区，卡片化 |
| 聊天页 | 顶栏 返回+头像+名字+在线状态；左右气泡（自己贴右、对方贴左），最大宽 268dp；底部「+ / 输入框 / 表情 / 发送」 |
| 我的 | 大圆角分组卡片（模型与接口、主题与明暗、导入角色卡、备份与导出、关于），QQ 设置的区块感 |
| 底栏 | 3 个 Tab：聊天 / 角色 / 我的，线性图标 + 文字，选中态用主色 |

「角色扮演」基调的落地：聊天页副标题「在线 · 角色扮演模式」；详情页「开场白 / 设定 / 世界书」分区命名；
消息与开场白用小说体排版（斜体动作 `*动作*` 原样保留，不渲染成格式）。

## 4. 需要你检视/拍板的 4 件事

1. **配色选哪一套**（A 奶油茶 / B 奶咖 / C 青瓷）？或某套要微调（主色深浅、背景冷暖）。
2. **QQ 感够不够**：会话行信息量（是否要显示「置顶」角标、未读红点、时间格式）、角色页是否要从 3 列改 2 列/更多列。
3. **详情页主次**：封面图 370dp 高是否太高？「开始聊天」占主位、世界书次之，是否符合你的使用习惯？
4. **聊天页**：气泡最大宽度、字号 14.5sp、是否要「角色卡头像在每条消息旁」（目前是，QQ 风格）。

## 6. 已知限制（不是缺陷，是本轮范围外）

- 无真实数据链路：会话列表/角色/聊天都是样例数据，点「开始聊天」不会真的跳转
- 未做：键盘弹出、长文滚动截断、深色切换按钮（通过 adb 参数或切换面板演示）
- App 图标仍是占位（「对话气泡+茶」的正式图标待做，M1 前处理）
- 样张里的素材来自本地真实角色卡，仅本地使用，未入库（`design/src/main/res/drawable-nodpi/` 已入库 6 张，体积约 550KB）
