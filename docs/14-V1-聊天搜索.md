## V1 Backlog 首批

### 聊天搜索（已落地）

目标：只做「能用」的搜索，不引入 FTS 排序/向量检索，先覆盖「找回某句话在哪个会话」。

- 数据层：
  - `data/db/MessageSearchHit.kt`（单独成文件，避免 Room KSP 同文件 POJO 解析问题）：
    `conversationId / messageId / conversationTitle / characterName / characterAvatar / content / createdAt`。
  - `ConversationDao.searchMessages(query, limit)`：`messages` inner join `conversations` inner join `characters`，
    `m.content LIKE '%' || :query || '%'`，按 `createdAt DESC, id DESC` 取最近 N 条。
  - `CharacterRepository.searchMessages(query, limit = 50)`：`Dispatchers.IO` + `trim()`。
- UI（`ui/chats/ChatListScreen.kt`）：
  - 点右上搜索图标进入搜索态：搜索框（`BasicTextField`，hint「搜索消息内容」）+ 右侧 ✕ 退出；
  - `onQueryChange` 200ms 去抖，`limit = 40`；
  - 结果分两段：「会话」（按标题/角色名/最后一条内容忽略大小写匹配）与「消息」（内容命中，两行预览）；
  - 空结果文案带查询词；点会话行打开该会话，点消息行**直接跳到那条消息**。
- 跳转定位（`ui/HomeScreen.kt` + `ui/chat/ChatScreen.kt`）：
  - 路由 `chat/{conversationId}?messageId={messageId}`（`messageId` 可选，默认 -1）；
  - `ChatViewModel.focusOnMessage(id)`：`repository.messageById(id)` 取 `createdAt`，
    再用 `messagesBefore(conversationId, target.createdAt + 1, Long.MAX_VALUE, PAGE_SIZE)` 取**命中处那一页**；
  - 聚焦模式：`messages = older`（不再合并尾部窗口），避免「命中处」与「最新消息」之间出现几千条空档；
  - `LaunchedEffect(focusMessageId)` 等目标进入列表后 `scrollToItem(index)`；`send()` 会退出聚焦模式回到最新窗口。
- 真机验收（TAS-AN00 / Android 12 / 1080x2340）：
  - 搜 `tea`：会话区 1 条、消息区多条，文案与命中一致；
  - 搜 `5800`（10k 会话中段）：1 条命中，点开后**准确落在 `#5800`**，上下文连续（`#5794`–`#5800`），上滑可继续加载更早页；
  - 截图：`docs/screenshots/beta-2/01-search-idle.png`、`02-search-results.png`、`03-jump-to-hit.png`。
- 已知限制：
  - 只支持子串匹配（无分词/拼音/多关键词）；中文需输入中文（ADB `input text` 只能 ASCII，故真机验证用英文与数字）；
  - 命中页与「最新消息」之间不连续是聚焦模式的有意取舍，退回列表再进会话即回到最新窗口。
