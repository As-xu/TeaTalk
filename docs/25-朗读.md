# 25 - 朗读（TTS，0.25.0）

## 目标

让聊天页能「听」回复：长按任意角色气泡 → 朗读；不用离开 App、不用复制到别的朗读工具。

## 范围取舍

- **只做系统 TTS**：设备已装语音引擎（TAS-AN00 上是 `com.huawei.hiai`，另有讯飞），音色/引擎交给系统设置。云端 `/audio/speech` 需要另一套密钥、计费与音频缓存，本版不做（接口已留好，见 `TtsEngine`）。
- **不做后台朗读**：切走 App 后系统可能中断朗读；真正保活（前台服务 + 通知）是 0.26.0 的事，且朗读没必要占着通知栏。
- **不做逐词高亮**：需要 `UtteranceProgressListener.onRangeStart`（API 26+ 且引擎支持度参差），收益低于成本。
- 自动朗读默认关：多数人不希望回复突然外放。
- 先清洗再朗读：Markdown 的 `**`、``` 代码块、链接语法直接念出来很难听，`TtsText.clean` 先剥掉。

## 交互

| 步骤 | 行为 |
| --- | --- |
| 朗读 | 长按角色气泡 → 「朗读」；首段开始前初始化引擎（首次约 0.1s） |
| 停止 | 朗读中再长按同一气泡 → 菜单变成「停止朗读」；或点设置页的「停止朗读」 |
| 切换 | 朗读中点另一条气泡的「朗读」→ 先停旧再读新的 |
| 自动朗读 | 设置页开关；开启后新回复落库即朗读第一条 |
| 语速 / 音高 | 设置页滑杆，0.5–1.5，实时写入，下一次朗读生效 |
| 试听 | 设置页「试听」用固定文本朗读，按钮在朗读中变为「停止朗读」 |

## 实现要点

- `data/tts/TtsText.kt`（纯 Kotlin，可单测）：
  - `clean`：去 ``` 代码块、行内 code 取内容、Markdown 链接取文字、去 `* _ ~ # > |` 与引号、去表格分隔行、压缩连续空格；
  - `segments`：按 `。！？!?；;…` 与换行断句 → 合并到 ≤ 200 字 → 超长句 `hardSplit` 硬切。上限 200 是多数引擎稳定合成的边界。
- `data/tts/TtsEngine.kt`：`speak(segments, rate, pitch, onSegment)` / `stop()` / `release()`；`TtsStopped`（用户停止，不算失败）与 `TtsException`（引擎不可用）。
- `data/tts/SystemTts.kt`：包 `android.speech.tts.TextToSpeech`。
  - 初始化走 `suspendCancellableCoroutine`，`onInit` 成功后才返回；语言优先 `Locale.getDefault()`，不可用回落 `Locale.CHINA`；
  - 逐段 `QUEUE_FLUSH` + 等 `onDone` 再读下一段：能得到「第几段」进度，也不会被引擎按长度截断；
  - 所有引擎调用切主线程；`stop()` 把未完成的 `CompletableDeferred` 以 `TtsStopped` 结束。
- `data/tts/TtsController.kt`：全应用单实例（`AppContainer.ttsController`）。
  - `StateFlow<State(messageId, index, total)>`：`messageId == null` 表示空闲；同一条再点 = 停止；
  - `speak(messageId, text)` / `preview(text)` / `stop()` / `release()`；失败经 `failed: StateFlow<Boolean>` 交给聊天页弹 Snackbar；
  - 日志：`tts.start`（message/segments/chars）、`tts.init.ok`（locale）、`tts.done`（stopped）、`tts.fail`、`tts.preview`。
- `data/model/AppPrefs.kt`：`ttsRate`（0.5–1.5，默认 1.0）、`ttsPitch`（同）、`ttsAutoRead`（默认 false）。
- `ui/chat/ChatScreen.kt`：
  - `ChatViewModel` 新增 `tts: TtsController`、`speakingMessageId: StateFlow<Long?>`、`speak()` / `stopSpeaking()`；
  - `AssistantBubble` 长按菜单新增「朗读 / 停止朗读」（只在角色气泡上，用户气泡仍是预览）；
  - `commitOnce` 里 `if (status == COMPLETE && prefs.ttsAutoRead)` 朗读第一条落库消息。
- `ui/tts/TtsSettingsScreen.kt`：语速/音高滑杆、自动朗读开关、试听按钮、当前段进度；入口在「我的 → 朗读」（`Routes.TTS`）。
- `AndroidManifest.xml`：`<queries><intent><action android:name="android.intent.action.TTS_SERVICE"/></intent></queries>`（Android 11+ 不声明就看不到已安装引擎）。

## 已知限制

- 切到后台后朗读可能被系统中断（无前台服务）；0.26.0 的保活只覆盖流式生成，朗读仍以「前台」为主。
- 引擎/音色不可在 App 内选择，完全跟随系统「文字转语音」设置；无中文语音包时只能提示失败。
- 只看第一条落库消息做自动朗读：群聊一次可能落多条，当前只读第一条（避免连读三条打断用户）。
- 语速/音高变化只在「下一次朗读」生效，不会即时改变正在播的音频。
