# 国际化（i18n）

> 状态：**已支持简体中文（默认）与 English**，随 0.2.0 交付。后续加语言按本文 §4 扩展即可。

## 1. 语言与回退

| 项 | 规则 |
| --- | --- |
| 基准语言 | 简体中文（`res/values/strings.xml`，其余语言缺词条时回退到这里） |
| 已支持 | 简体中文 `zh-CN`、英语 `en` |
| 默认行为 | 跟随系统（系统是中文→中文；系统是英文→英文；其它语言→回退中文） |
| 手动切换 | 我的 → 语言：跟随系统 / 简体中文 / English，立即生效并持久化 |

用户拍板依据：m02480（「1. 选择 B 默认中文；2. 语言入口放我的>语言可以；3. 英文用建议 style」）。

## 2. 资源布局

```
app/src/main/res/
  values/strings.xml          # 中文（基准）
  values/plurals?             # 复数在 values/strings.xml 内的 <plurals> 里
  values-en/strings.xml       # 英文，只含用户在英文下能看到的所有词条
  values-night/colors.xml     # 暗色背景色（窗口背景，防启动闪白）
  xml/locales_config.xml      # 声明支持的语言（系统「应用语言」设置里会显示）
```

规则：
- **所有 UI 文案必须走资源**，Kotlin 里不再写中文（品牌字「茶」、角色卡/聊天内容属于数据，不在 i18n 范围）。
- 复数用 `<plurals>` + `pluralStringResource`：`chatlist_waiting`（有 1 个角色在等你 / N 个角色在等你）、`characters_count`。
- 带占位符的文案用 `%1$s` / `%1$d`，不要在 Kotlin 里拼句子（语序问题）。
- `app_name`：中文「茶话」，英文 `TeaTalk`（桌面图标名随之变化）。

## 3. 实现方式

- `MainActivity.attachBaseContext()`：读 `LanguagePrefs` 的 `language_tag`，非空则 `createConfigurationContext` 覆盖 Locale；为空则用系统配置（API 33+ 可吃到系统「应用语言」设置）。
- `LanguagePrefs`（`MainActivity.kt` 内）：SharedPreferences `teatalk_prefs` / `language_tag`，`null` = 跟随系统。键名固定，不随语言变化。
- 切换：我的 → 语言 → 写入 prefs → `recreate()`，整棵界面按新 Locale 重建。
- `data/UiText.kt`：ViewModel/数据层不持有 `Context`，文本用
  ```kotlin
  sealed interface UiText {
      data class Res(@StringRes val id: Int, val args: List<Any> = emptyList()) : UiText
      data class Raw(val text: String) : UiText   // 卡片名、错误里的原始字符串等
      fun resolve(context: Context): String
  }
  ```
  UI 层 `uiText.resolve(context)`；`Raw` 用于卡片数据与系统异常消息（不翻译）。
- 系统栏图标明暗、主题深浅仍跟随系统（语言与深浅色互不影响）。

## 4. 新增一门语言（例：日语）

1. 复制 `values-en/strings.xml` → `values-ja/strings.xml`，全部翻译（缺的会回退中文）。
2. 复数：在 `values-ja/strings.xml` 里加同名 `<plurals>`（日语通常只保留 `other`）。
3. `res/xml/locales_config.xml` 加 `<locale android:name="ja"/>`。
4. 我的 → 语言 的选项列表加「日本語」（`LanguagePicker` 里 `options` 数组 + `values-ja` 的 `language_name` 词条）。
5. 跑一遍：系统语言切日语 + App 内选日语，检查长文案（德语/俄语尤其长）是否截断。

## 5. 已知限制（M0 范围外）

- 角色卡文本、聊天记录内容不翻译（属于创作内容，按原样显示）。
- 语言切换会 `recreate()`，聊天页若在输入中会丢失未发送草稿（M1 聊天持久化时一起处理）。
- 暂不跟随「系统应用语言」与 App 内选择的联动细则：App 内选择优先于系统设置。
- 屏幕阅读器（TalkBack）的 contentDescription 已用资源，但尚未做无障碍专项验收。
