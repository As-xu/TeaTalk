## 7. 踩坑记录（跨步骤通用）

- **Room + KSP：`@Embedded` POJO 与 `@Entity` 同文件 → 编译期报**
  `[ksp] ...Entities.kt:39: [MissingType]: Element '...CharacterWithLastMessage' references a type that is not present`。
  拆到独立文件 `CharacterWithLastMessage.kt` 后同一构建通过（clean 也复现，确认不是增量缓存）。→ 以后 Room 的查询 POJO 一律单独成文件。

  `error: resource attr/colorControlNormal not found`。删掉该行即可（`Icon()` 会按 `LocalContentColor` 自己 tint）。
