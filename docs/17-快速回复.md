# 17 - 快速回复（Quick Replies）

## 目标

常玩 RP 的人每次开新局都要重复输入同样几句话：

- 旁白/导演指令（「用第三人称、每段不超过 200 字」）
- OOC 提示（「OOC: 注意保持角色语气」）
- 场景切换模板（「时间跳到第二天早上」）

SillyTavern 用 Quick Replies 解决（可带脚本的按钮条）。0.19.0 做的是**最小可用版本**：
一条可复用的文本片段，管理页可增删改、可停用，聊天时点一下 `/` 就插进输入框，
不掺脚本执行——先解决「重复打字」，脚本化留给后续。

## 实现

### 数据层（DB v12）

`data/db/QuickReplies.kt`：

```kotlin
@Entity(tableName = "quick_replies")
data class QuickReplyEntity(
    @PrimaryKey(autoGenerate = true) val id: Long = 0L,
    val title: String = "",
    val content: String = "",
    val sortIndex: Int = 0,
    val enabled: Boolean = true,
    val createdAt: Long = 0L,
) {
    fun displayLabel(): String =
        title.trim().ifEmpty {
            content.lineSequence().firstOrNull { it.isNotBlank() }?.trim().orEmpty()
        }
}
```

- `QuickReplyDao`：`observeAll()` / `all()` 均按 `sortIndex ASC, id ASC` 排序，
  另有 `upsert` / `update` / `delete` / `deleteById`。
- `TeaTalkDatabase` 升到 **v12**，`MIGRATION_11_12` 只建一张表：

```sql
CREATE TABLE IF NOT EXISTS quick_replies (
    id INTEGER PRIMARY KEY AUTOINCREMENT NOT NULL,
    title TEXT NOT NULL,
    content TEXT NOT NULL,
    sortIndex INTEGER NOT NULL,
    enabled INTEGER NOT NULL,
    createdAt INTEGER NOT NULL
)
```

  注意：**建表 SQL 不写任何 `DEFAULT`**，列全部 `NOT NULL`，与实体声明严格一致
  —— 这是 0.18.1 那次 Room 迁移校验崩溃留下的硬性约定（见 `docs/16-正则与变量.md`）。
- `AppContainer` 注册 `MIGRATION_11_12` 并把 `quickReplyDao()` 传进 `CharacterRepository`；
  仓库提供 `observeQuickReplies()` / `enabledQuickReplies()` / `saveQuickReply()` / `deleteQuickReply()`。

### UI

- 管理页：`ui/quick/QuickRepliesScreen.kt` + `QuickRepliesViewModel.kt`
  - 列表行 = 标题（无标题则内容首行）+ 内容预览 + 启用开关 + 编辑 + 删除
  - 空态：「还没有快速回复」+ 说明 + 「新建快速回复」
  - 编辑对话框：标题（可选）/ 内容（必填，空了保存按钮置灰）/ 排序 / 启用
  - 删除走二次确认（`确定删除「X」？此操作不可撤销。`）
  - 入口：`我的 → 快速回复`（图标 ✏️，位于「正则脚本」之后）
- 聊天页：输入条最左侧新增 `/` 按钮（在群聊 `@` 之后、`+` 之前），点开
  `ModalBottomSheet` 列出**已启用**片段，点条目即把 `content` 追加进输入框并关闭面板；
  列表为空时显示「还没有启用的快速回复」。
- 路由：`Routes.QUICK_REPLIES = "quickreplies"`。

## 取舍

- **只插入、不发送**：点片段只把文本放进输入框，是否发送由用户决定，避免误触直接扣 token。
- **不做变量/脚本**：片段的 `content` 是纯文本原样插入，不解析 `{{getvar}}`；
  想用变量的人应该走正则/变量那套（0.18.0），或在片段里直接写固定文本。
- **追加而非替换**：插入是「已有内容 + 空格 + 片段」，方便一句话里拼多个指令；
  想清空再插，手动删一下即可。
- **无标题也能用**：标题只是为了列表可读，真正的文本是 `content`；
  `displayLabel()` 在无标题时退化为内容首行，避免列表里出现空行。
- **排序维持手动**：没有「最近使用」自动排序，避免列表顺序在使用中漂移；
  需要常驻顶部的，把 `sortIndex` 调小即可。
